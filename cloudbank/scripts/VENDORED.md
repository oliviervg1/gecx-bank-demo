# Lifecycle, Sync & Audit Scripts (`cloudbank/scripts/`)

All scripts in `cloudbank/scripts/` are licensed under the Apache License, Version 2.0 (`LICENSE` at repository root) and run strictly inside the hash-locked `cloudbank/` Python environment (`uv run --locked`) with zero external `sys.path` parent walks.

| Script | Provenance | Local Hardening & Scope |
| :--- | :--- | :--- |
| `audit_agent.py` | Focused read-only Gemini Composite v2 auditor authored for Cloudbank (`Apache-2.0`). | Enforces `gemini-composite-v2` inheritance, `en-GB-Chirp3-HD-Aoede` voice parity, concise prebuilt speaking style (`<= 25` words, zero Director's Notes), `Affective_Delivery_and_Voice_Guidelines`, `Scope:`-guarded normalization, inline `<tag>` vocabulary parity against `shared/composite_v2_tags.json`, and `cxas_scrapi` rules `I015` / `V104` with zero `--remediate` mutators. |
| `gecx_workspace.py` | Adapted from CX Agent Studio (`CXAS`) workspace configuration utilities (`Apache-2.0`). | Supports `CLOUDBANK_GCP_PROJECT_ID`, `CLOUDBANK_LOCATION`, and `CLOUDBANK_APP_ID` environment variable overrides, plus automatic fallback from gitignored `gecx-config.json` to `gecx-config.example.json` for offline tests and CI. |
| `manage_app.py` | Adapted and trimmed from CX Agent Studio (`CXAS`) `cxas_scrapi` deployment helpers (`Apache-2.0`, renamed from `manage_ces_app.py`). | Enforces `--yes` / TTY confirmation whenever the resolved target resource equals `ws.prod_app_resource`; fails closed on any `ImportAppResponse.warnings`; verifies remote `ListTools` declarations match `cxas_app/Cloudbank` with zero orphan tools. |
| `run_golden_evals.py` | Adapted from CX Agent Studio (`CXAS`) golden evaluation sync and runner (`Apache-2.0`). | Compiles multi-segment NAIVE golden turns in chronological runtime execution order (`toolCall` -> `agentResponse` -> `agentTransfer`) and runs server-side evaluations with `FAKE` or `REAL` tool behaviour. |
| `sync_shared.py` | Authored directly in this repository (`Apache-2.0`). | Deterministically syncs `cxas_shared/callbacks/*.py` into all 4 agents (8 callback files), splices `cxas_shared/controller_common.py` into all 4 Python controllers and `shared/official_help_hosts.json` into `assist_everyday_banking`, and syncs `customer_snapshot` + `first_name` in `evals/{goldens,simulations}/*.yaml` from `shared/personas/*.json`. |
